# Smart Dustbin System using ESP8266

An IoT-based smart dustbin system developed using ESP8266, HC-SR04 ultrasonic sensor, and SG90 servo motor to enable touch-free and automated waste disposal.

## Project Overview

This project was developed as a college engineering project to create a smart and hygienic waste management solution using sensor-based automation. The system automatically detects nearby objects and opens the dustbin lid without physical contact.

## Features

* Automatic lid opening mechanism
* Touch-free operation
* Distance detection using ultrasonic sensor
* Real-time sensor-based automation
* Compact and efficient embedded system design

## Components Used

* ESP8266
* HC-SR04 Ultrasonic Sensor
* SG90 Servo Motor
* Jumper Wires
* Breadboard
* Power Supply

## Technologies Used

* Embedded Systems
* Arduino IDE
* C/C++ Programming
* IoT Fundamentals

## Working Principle

The HC-SR04 ultrasonic sensor continuously measures the distance of nearby objects. When an object is detected within a specified range, the ESP8266 processes the sensor data and controls the SG90 servo motor to automatically open the dustbin lid. After a short delay, the lid closes automatically.
